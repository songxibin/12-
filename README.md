# 📅 12 周图像识别学习任务清单

## **第 1 个月：图像处理与基础**
- **第 1 周**
  - 学习：Python 基础（NumPy 数组、Matplotlib 绘图）
  - 实践：读取/显示图片，用 NumPy 改变像素值（如翻转、灰度化）
  - https://github.com/eastmountyxz/ImageProcessing-Python
- **第 2 周**
  - 学习：OpenCV 基础（图像加载、颜色空间、边缘检测）
  - 实践：写一个小脚本，对照片进行缩放、旋转、滤波
- **第 3 周**
  - 学习：数字图像处理基础（直方图均衡、卷积滤波）
  - 实践：自己实现卷积操作（用 NumPy），体验图像锐化/模糊
- **第 4 周**
  - 学习：传统特征提取（SIFT、HOG、ORB）
  - 项目：手写数字特征提取 + KNN 分类  

---

## **第 2 个月：深度学习与 CNN**
- **第 5 周**
  - 学习：神经网络基础（感知机、激活函数、损失函数）
  - 实践：用 NumPy 实现一个小型两层神经网络
- **第 6 周**
  - 学习：PyTorch 或 TensorFlow 基础（张量运算、模型构建）
  - 实践：在 MNIST 数据集上训练一个简单的全连接网络
- **第 7 周**
  - 学习：卷积神经网络（CNN：卷积层、池化层）
  - 实践：从零写一个 CNN，在 MNIST 上跑通
- **第 8 周**
  - 学习：经典网络结构（LeNet、VGG、ResNet）
  - 项目：用 PyTorch 在 CIFAR-10 上训练 CNN 并可视化结果  

---

## **第 3 个月：进阶与实战**
- **第 9 周**
  - 学习：迁移学习（加载 ResNet/EfficientNet 预训练模型）
  - 实践：在小数据集（比如猫狗分类）上微调模型
- **第 10 周**
  - 学习：数据增强（Data Augmentation）、正则化、Dropout
  - 实践：对比“无增强”和“有增强”在 CIFAR-10 上的效果
- **第 11 周**
  - 学习：目标检测基础（YOLO、SSD）
  - 实践：用预训练 YOLO 模型检测图片里的物体
- **第 12 周**
  - 项目收尾：选择一个小项目并完成
    - 猫狗分类器
    - 人脸识别 demo
    - 摄像头实时物体检测  
  - 把项目整理上传到 GitHub
